## 1. デザイントークン

Astryx では `defineTheme({ tokens })` で上書きする。Astryx 側のトークン名の対応は 1.7 にまとめた。

決まり:
- 赤は失敗アイコンの線だけに使う。文字・背景・行は赤くしない。必ず「失敗」や理由の文と一緒に出す（C3、C5）。
- 青は、1画面で主ボタン 1 つと進捗に限る（【第三者採取】Notion も青は 1 ページに 1 回）。
- グラデーション、紫、色付きのピル、件数カード、絵文字は使わない（E1、E2、C4）。
- ダークモードは任意。値を足すなら bg `#191919`、text `#F0EFED`、浮く面 `#252525`、縁 `#383836` にする（【第三者採取】）。

### 1.2 文字

フォント: `"Segoe UI Variable Text", "Segoe UI", "Yu Gothic UI", "Meiryo UI", "Noto Sans JP", ui-sans-serif, sans-serif`
- Notion の指定は `ui-sans-serif, -apple-system, BlinkMacSystemFont, "Segoe UI Variable Display", "Segoe UI", …` で、日本語のフォントを指定していない【実測】。
- Windows で日本語がどのフォントになるかを固定するため、`Yu Gothic UI` を明示する【独自】。
- 数字には `font-variant-numeric: tabular-nums` を付ける。

| 役割 | サイズ / 行の高さ | 太さ | 色 | 出典 |
|---|---|---|---|---|

| 画面タイトルの続き（「132 / 480 件　残り約6分」） | 30 / 38 | 400 | text-2 | 【独自】 |
| セクション見出し | 16 / 24 | 600 | text | 見出しの太さ 600【書き出しCSS】。サイズは本文と同じ【独自】 |
| 本文・一覧・表のセル・操作部品 | 14 / 20 | 400（ラベルと主ボタンは 500） | text | 操作部品は 14px【第三者採取】、データベースは 0.875rem【書き出しCSS】 |

### 1.6 部品の共通スタイル

  - 高さ 28、左右 8、角丸 6、文字 14/500、色 text-2。

  - 高さ 28、左右 8、角丸 6、背景 hover の色、文字 14、右に 12px の下向き矢印。

  - 溝は幅 28・高さ 16・角丸 8。オフは `rgba(44,44,43,0.16)`、オンは accent。

  - `<button role="switch" aria-checked>` にし、右に「オフ」「オン」の文字を出す（text-2、12）。
- **フォーカス**: すべての操作部品に `outline: 2px solid accent; outline-offset: 2px` を付け、キーボードでたどれるようにする。

### 1.7 Astryx のトークンとの対応

`defineTheme` の `tokens` に入れる。トークン名は Astryx 0.7.16 の docs `tokens` で確かめた。radius と size のそれぞれの意味は実装時に `astryx docs tokens/tokens-radius`、`tokens/tokens-size` で確かめること。

| Astryx | 値 |
|---|---|
| `--color-text-primary` | `#2C2C2B` |
| `--color-text-secondary` | `#7D7A75` |
| `--color-background-body` | `#FFFFFF` |
| `--color-background-surface` / `--color-background-muted` | `#F9F8F7` |
| `--color-border` | `rgba(42,28,0,0.07)` |
| `--color-border-emphasized` | `rgba(28,19,1,0.11)` |
| `--color-accent` / `--color-on-accent` | `#2383E2` / `#FFFFFF` |
| `--color-error` | `#E03E3E`（アイコンだけに使う） |
| `--radius-element` / `--radius-container` / `--radius-page` | 6px / 10px / 12px |
| `--size-element-md` / `--size-element-sm` | 28px / 24px |
| motion の `character` | `crisp`（行き過ぎなし）。Astryx には Reduce Motion で長さを 200ms までにする上限がある |

Astryx の部品の見た目がこの仕様と合わない場合は、部品を作り直さずにトークンで寄せる。それでも寄らない部分だけ StyleX で上書きする。

## 3. 動き（Asobi Motion）

### 3.1 方針

Asobi Motion の手順のうち、使ったもの:
- component-motion の手順（状態遷移表、性格、硬さ、reduced motion）
- keyframe-craft の「動きを身の回りのものに置き換える一文」
- principles のうち、restraint（配分）、accessibility、materiality
- references の timing-and-order と easing-catalog

決めたこと:
- **見せ場は1つ**: 再試行が成功した行が抜けていく動きだけにする（restraint: 見せ場は一つ、読む場所は動かさない）。ほかは状態の変化を知らせる最小限の動きにとどめる。
- **常時ループは 0**: 例外は「再試行中」の回転だけで、意味のあるループとして扱う。
- **硬さ**: ポキッ寄りの硬いもの。行き過ぎも伸び縮みも付けない（materiality の例外「業務UIでは伸縮を弱め、硬い側に寄せる」）。ホバーの「ぷよん」系のイージングは使わない。
- **性格**: 「一生懸命」。取り込みや再試行の間は働いていることを静かに見せ、終わったら黙って片付く。エラーには遊びを入れない（揺らす、跳ねるはしない）。
- **動きの一文**:
  - 進捗: 「メーターの針がジリッと進む」
  - 再試行の成功: 「片付いた伝票を束からスッと抜き取る」
  - 影響の案内: 「引き出しをスーッと開けると注意書きが見える」
  - トグル: 「壁のスイッチをパチッと入れる」
  - メニュー: 「棚の扉を手前に開ける」
- **イージングは2本だけ使う**:
  - `--ease-decel = cubic-bezier(0, 0, 0.1, 1)`（easing-catalog「シュッ」karory slideIn）: 出る・進む動き
  - `--ease-firm = cubic-bezier(0.83, 0, 0.17, 1)`（easeInOutQuint【本人値】、「カチッ」）: 行が抜けて詰まる動き
  - 不透明度だけの変化は linear にする（【本人値】comimi の opacity 0.15〜0.3 秒 linear）。
- **開始時刻**: すべて `--delay` からの足し算で書く（timing-and-order の「演出の連結」）。

### 3.3 reduced motion（`prefers-reduced-motion: reduce`）

- 位置・大きさ・高さの変化は止め、不透明度の短い変化だけ残す。
- `--delay` と `--t-hold` は 0s にする。待たせない。
- 最終状態は必ず見えるようにする。

| 動き | reduce のとき |
|---|---|
| 進捗バー | transition をなくし、すぐ新しい長さにする。進捗は「132 / 480 件」の文字で伝わる（accessibility の例外「進捗は止めても分かる表示に」） |
| 今のファイル | opacity の差し替え 0.15s を残す |
| メニュー | translate をなくし、opacity 0.15s だけにする |
| 再試行中の輪 | 回転を止め、同じ輪の opacity を 1→0.4→1 で 1.2s ease-in-out のループにする。ボタンの文字「再試行中…」と `aria-busy="true"` も付ける |
| 行が抜ける | 待ちを 0 にし、opacity 0.15s のあと高さはすぐ 0 にする |
| トグル | つまみはすぐ動かし、溝の色の変化 0.2s だけ残す |
| 影響の案内 | 高さはすぐ開き、中身の opacity 0.2s（遅延 0）だけにする |
| モーダル | scale をなくし、opacity 0.2s だけにする |

### 3.4 アクセシビリティ（動きと同時に入れる）

- 状態の一文の領域は `role="status"` と `aria-live="polite"` にする。件数の読み上げは 10 秒に 1 回まで【独自】。
- 進捗バーは `role="progressbar"` にし、`aria-valuenow`、`aria-valuemax`、`aria-valuetext="132 / 480 件"` を付ける。
- 「一時停止」のボタンには `aria-haspopup="menu"` と `aria-expanded` を付ける。メニューは矢印キーで移り、Esc で閉じて、フォーカスをボタンに戻す。
- 再試行の行は、処理中に `aria-busy`。成功したら「◯◯を取り込みました」を live region で 1 回読み上げ、行が消えたらフォーカスを次の行の「再試行」に移す（次の行がなければ見出しに移す）。
- トグルは `role="switch"` と `aria-checked` にする。影響の案内は `aria-live="polite"` で読み上げ、開いてもフォーカスはセレクトに残す。
- 5秒を超えて自動で動くのは、取り込み中の進捗と再試行中の輪だけ。どちらも止める手段（一時停止）がある（WCAG 2.2.2）。
